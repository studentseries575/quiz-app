# 🧠 Quiz Web Application

## 📌 Project Description
This project is a responsive quiz application developed using HTML, CSS, JavaScript, and Bootstrap. It allows users to attempt multiple-choice questions with a timer and view results.

---

## 🚀 Features

- Multiple-choice questions
- Countdown timer (10 seconds)
- Progress bar (multi-colored)
- Correct & wrong answer highlighting
- Previous/Next navigation
- Result summary table
- Download result as PDF
- Responsive design

---

## 🛠 Technologies Used

- HTML
- CSS
- JavaScript
- Bootstrap
- html2pdf.js
